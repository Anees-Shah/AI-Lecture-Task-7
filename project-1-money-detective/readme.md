The script acts as a financial auditor. First, it cleans the messy data by removing hidden spaces, quotation marks, and commas from the amounts, ensuring the math won't break. It then separates money coming in (income) from money going out (expenses).
To find the 'leaks', it groups all expenses by the Merchant Name and the Exact Amount. If it sees the exact same merchant and exact same amount more than once in a single month, it flags it. Finally, it checks the merchant's name against a list of 'subscription keywords' (like Netflix, Gym, Premium). If it finds a keyword, it labels it a 'Subscription/Recurring' charge; otherwise, it labels it a 'Repeated/Duplicate' charge. It then prints a report showing the merchant, the amount, how many times it hit, and the exact dates
